# リリース候補監査（フェーズ125）

| 監査領域 | 確認内容 | 結果 |
|---|---|---|
| 家族権限 | 家族IDを受け取る地理見守りの作成・閲覧・確認を検査 | 作成はguardian、閲覧・確認はメンバー限定へ補強 |
| 画面状態 | Home、FamilyDetail、遅延読み込み、オフライン復帰の状態を確認 | 空状態・スキップ先・多言語ローディング・復旧表示を確認 |
| 成果物 | 型検査、Vitest、低メモリ本番ビルド、公開プレビューを確認 | 各コマンドの成功と成果物サイズ警告を記録 |

本監査では、500KB超の既知のコード分割警告を**警告**として扱います。FamilyDetailの日常ツールは明示操作後の遅延チャンクに分離済みであり、初期表示の重要導線を優先します。
