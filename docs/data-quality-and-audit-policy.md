# 家族共有データ品質・監査方針

KizunaSyncでは、見守り・招待・共有設定を**高優先度操作**として扱います。これらの操作では、家族グループ、実行者、操作種別、最小限の結果、作成時刻を追跡対象とし、本文メモ・位置・健康値などの不要な内容を監査用途に複製しません。

| 操作 | 追跡する最小情報 | 追跡しない情報 |
|---|---|---|
| 安心チェックイン | 家族、実行者、状態、時刻 | 任意メモ本文 |
| 招待 | 家族、実行者、招待する役割、時刻 | 招待リンクの秘密値 |
| 共有設定 | 家族、実行者、変更フィールド、時刻 | 位置・健康データの実値 |

クライアントでは入力を正規化し、送信中の二重操作を止めます。保存に失敗した場合は入力を保持して再試行を明示し、オフラインキューや競合検知と合わせて意図しない重複送信を防ぎます。
